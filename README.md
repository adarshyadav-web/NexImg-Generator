# NexImg Generator

A high-quality random image generator that fetches fresh inspiration from the Picsum API in a beautiful masonry grid.

## 🚀 Features

- **API Integration**: Fetches random, high-quality images.
- **Masonry Grid**: Fluid, responsive layout for image discovery.
- **Dynamic Controls**: Request new images instantly.
- **Sleek UI**: Modern controls and interactive image cards.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
- **Picsum Photos API**
